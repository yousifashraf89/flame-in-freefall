# 🔥 Flame in Freefall: NASA Space Apps 2026

**Challenge:** Flame in Freefall: SI-Powered Fire Safety Insights from Microgravity Combustion Data

A dashboard that turns all 24 combustion investigations in NASA's Physical Sciences Informatics (PSI) database into
fire-safety answers for crewed habitats (ISS, Moon base and rovers, spacesuits, Mars).

## What it does
| Page | What you get |
|---|---|
| 🏠 Overview | The problem, key numbers, and the coverage map |
| 🧑‍🚀 Your habitat | Auto-generated briefing, an explainable relevance ranking, investigation cards, and a one-page PDF brief |
| 🏗️ Designer | **Moon-base fire-risk designer:** choose the atmosphere and the materials on board and get a fire-risk card (evidence traffic light per material, NFPA 99B check, predicted fire behaviour, detection/suppression guidance, tests to run) |
| 🕳️ Data gap | Where tests exist vs where crews will live, recommended next experiments, and "will my material burn here?" |
| ⚖️ Trade-off | **The atmosphere dilemma:** pre-breathe index vs NFPA 99B increased-burning limit vs fire-data coverage. Below ~11.8 psi, normal-breathing atmospheres all fall in the increased-burning zone |
| 📈 Predict | ML model (FLEX, 274 droplet fires): burning rate, flame lifetime and chance of self-extinction, with uncertainty band, extrapolation warning and cross-validation |
| 🧯 Equipment | Suppression (O₂ and diluent effects), detection (smoke-particle growth), prevention (microgravity vs 1-g flammability) |
| 🌍 Earth | Oxygen-enriched places on Earth (hyperbaric chambers, oxygen-enriched rooms) mapped against NASA's tests |
| 🔬 Explore | Side-by-side comparison and a filterable test explorer with CSV download |
| 💬 Ask | AI Q&A grounded in PSI text, citing investigations (needs an API key) |
| ℹ️ About | Methods, assumptions, glossary, Earth benefits, AI-use disclosure |

**Key finding:** of 2,027 tests with recorded O₂ and pressure, only 74 fall in the planned Moon-base atmosphere
(≥30% O₂, ≤10.2 psi), and **none of them used solid materials**.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Deploy
Streamlit Community Cloud → New app → `app.py`. Optional: add `ANTHROPIC_API_KEY = "..."` under Secrets for the AI chat.

## Data pipeline (already run; outputs are in data/)
1. `harvest_psi.py` downloads PSI metadata + experimental tables (public PSI API)
2. `normalize_psi.py psi_combustion_data` builds `data/tests_normalized.csv` (one schema for 2,961 tests)
3. `extract_attributes.py` (optional; needs ANTHROPIC_API_KEY) builds `data/investigations_enriched.json`
   with AI-extracted attributes, which the app shows labelled "(AI)". Have a person review it.
Raw tables used by the model and the equipment charts are in `data/raw/`.

## Methods & assumptions
- **Relevance score** = 35% fire-safety focus + 30% closeness of tested conditions + 20% fuel relevance + 15% data richness.
- **Coverage** = exp(−d/0.15), where d is the distance to the nearest test in (O₂ fraction, log₁₀ pressure).
- **Model:** gradient-boosted trees (scikit-learn) with quantile regression for 10–90% bands. 5-fold cross-validation:
  burning rate R² ≈ 0.65; self-extinction 82% accuracy vs 69% baseline. A CFI-G ignition model was tested and
  dropped (no skill over the baseline).
- Where PSI tables omit O₂ or pressure, ISS cabin air (≈21%, 14.7 psi) is assumed and flagged (`o2_source`, `p_source`).
